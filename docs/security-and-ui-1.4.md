# Safety follow-up — 1.4 / versionCode 5

New reports and appeals create durable moderator notifications, an appbar unread badge, live WebSocket updates and bilingual Android tray notifications. Reading the inbox acknowledges a captured cursor, preserving notifications received during loading. Push delivery uses per-device SHA256 receipts and exponential retries; new device tokens can receive outstanding unread items from the preceding seven days. Failed delivery remains pending. The native intent bridge opens the review inbox on cold/warm notification taps. Moderator permissions remain database-authoritative.

Account restrictions have an opaque full-screen DS gate. It displays the actual moderator reason, permanent/temporary status, exact local expiry, remaining time, an in-game appeal, support email and sign-out. Cached known account bans remain gated offline; older cached sessions without a safety state are checked before game access. Escape/background taps cannot close the gate. Expiry is verified with the server before removing it. API and socket enforcement remains authoritative. Social/economy restrictions explain their scope while allowing chess; they no longer close gameplay sockets. Moderators can also choose three days.

Permanent account bans preserve identity while public friends/chat/group metadata and profile responses show a banned avatar, no cosmetics and zero rating/statistics. All leaderboard sorts exclude these accounts. Arabic/English avatar variants are chosen by the viewing client. Underlying data remains intact for appeals; revoking the permanent account penalty restores it. Temporary bans and social/economy penalties do not zero public data.

Automatic policy is conservative and deterministic: five distinct genuine server-issued reward-session secrets belonging to other accounts used within ten minutes cause an economy restriction. Repeated use of one secret counts once per 24 hours. First sanction is one hour; repeat sanctions within 90 days increase to one day, then one week. No automatic permanent ban is imposed. The audit identifies the action as automatic, supplies a bilingual reason and notifies moderators. Existing suspicion events, ordinary illegal chess moves, stale/replayed own sessions, offline claims and report counts never trigger this policy. Moderators are protected from automatic sanctions. No system is infallible; appeals and manual revocation remain available. Store/reward validation, authenticated server state, rate limits and trusted evidence remain in effect independently.

Google Play Integrity remains prepared and disabled until Play configuration is available; installing the official GitHub APK is not itself a violation. This update does not claim to identify every modified binary or judge voice/video content automatically.

Validation: isolated security tests cover notification cursors, live hooks, per-device push retry/dedupe, scope enforcement, permanent masking/restoration and automatic thresholds. A real HTTP/WS server test verifies live badge payloads, socket behavior, friends/profile outputs, all four leaderboard sorts and appeal restoration. Call, privacy, rating, economy, store and mobile regression suites pass. Browser QA covers Arabic/English permanent and temporary gates, appeal submission, logout, blocked Escape, social restrictions, public avatar and moderator badge at mobile sizes. Native APK/AAB are built and signature/bundle validated. No physical Android handset is connected; tray delivery and tapping need final verification on Gojo's handset with notification permission enabled.
